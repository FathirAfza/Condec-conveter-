Second pre-release of Condec, a Windows file converter that runs entirely on your device, with no internet connection.

## Fixed

- **DXF → DWG failed with `CadNotSupportedException`** for DXF files saved in older versions, such as R12 DXF from image-to-DXF tools and many other exporters. Condec now writes those drawings as DWG 2000 (and R2007 drawings as DWG 2010), which every current CAD program opens. Drawings in a version DWG can store keep their version.
- **DXF files without a TABLES section** (layers, linetypes and text styles left out) no longer fail when converted to DWG; the standard entries are added.
- A DWG older than AutoCAD R14 now gets a clear message saying the version isn't supported, instead of a generic error.

Everything else is the same as v0.1.0-beta.1.

## Trying it without installing (portable)

1. Download `Condec_v0.1.0-beta.2_x64_portable.zip` and extract it anywhere.
2. Run `Condec.exe`. If SmartScreen appears, choose **More info** then **Run anyway** (the file isn't signed by a trusted publisher yet).

The portable build brings its own .NET, Windows App Runtime, and LibreOffice. Nothing is installed or registered; app data still lives in `%LOCALAPPDATA%\Condec`.

## Installing or updating (MSIX)

This package is signed with a new test certificate, so import the `Condec.cer` from **this** release even if you trusted the one from beta.1.

1. Download `Condec_v0.1.0-beta.2_x64.msix` and `Condec.cer`.
2. Open PowerShell **as administrator**, go to the download folder, and import the certificate:
   ```powershell
   cd "$env:USERPROFILE\Downloads"
   Import-Certificate -FilePath .\Condec.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
   ```
   Without PowerShell: double-click `Condec.cer`, choose **Install Certificate**, **Local Machine**, then **Place all certificates in the following store**, **Trusted People**.
3. Double-click the `.msix` file and choose **Install** (or **Update** if beta.1 is installed). Or from PowerShell:
   ```powershell
   Add-AppxPackage -Path .\Condec_v0.1.0-beta.2_x64.msix
   ```

Requirements: Windows 10 version 1809 (build 17763) or later, 64-bit. Check your download with `SHA256SUMS.txt`.

## Known limitations

- x64 only.
- PDF → DXF/DWG: line widths and dash patterns aren't mapped to lineweights and linetypes yet; fills are written as closed outlines.
- Audio/video conversion isn't included yet.
