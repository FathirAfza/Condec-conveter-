Fourth pre-release of Condec, a Windows file converter that runs entirely on your device, with no internet connection.

## New

- **Pictures to CAD.** PNG, JPG, BMP, GIF, TIFF and (where Windows has the codec) HEIC and WebP can now be converted to **DXF** and **DWG**. Condec traces the dark shapes of the picture into closed outlines, sized in millimeters from the picture's resolution. A DWG is made through a DXF: the drawing is written as DXF first, then converted to DWG, all in one step. This works best for drawings, logos and scans; a photo gives only a rough result.
- **Your language.** The app now follows the Windows language list. English and Indonesian are included; any other language shows English.

## Improved

- Tracing large or noisy pictures, and scanned PDFs, is much faster (a noisy 1200 × 800 picture went from 37 seconds to about one).
- The README is now in English.

Everything else is the same as v0.1.0-beta.3.

## Trying it without installing (portable)

1. Download `Condec_v0.1.0-beta.4_x64_portable.zip` and extract it anywhere.
2. Run `Condec.exe`. If SmartScreen appears, choose **More info** then **Run anyway** (the file isn't signed by a trusted publisher yet).

## Installing or updating (MSIX)

This package is signed with a new test certificate, so import the certificate from **this** release even if you trusted an earlier one. The most reliable way is to export it from the package itself. In PowerShell **as administrator**, one command at a time:

```powershell
cd "$env:USERPROFILE\Downloads"
```
```powershell
Export-Certificate -Cert (Get-AuthenticodeSignature .\Condec_v0.1.0-beta.4_x64.msix).SignerCertificate -FilePath .\condec-signer.cer
```
```powershell
Import-Certificate -FilePath .\condec-signer.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
```
```powershell
Add-AppxPackage -Path .\Condec_v0.1.0-beta.4_x64.msix
```

If Condec is running, close it first. Requirements: Windows 10 version 1809 (build 17763) or later, 64-bit. Check your download with `SHA256SUMS.txt`.

## Known limitations

- x64 only.
- Picture → DXF/DWG traces outlines only: no colors, no filled areas, no text recognition.
- PDF → DXF/DWG: line widths and dash patterns aren't mapped to lineweights and linetypes yet; fills are written as closed outlines.
- Audio/video conversion isn't included yet.
