Pre-release pertama Condec: konverter file untuk Windows yang bekerja sepenuhnya di perangkat, tanpa internet.

## Yang ada di versi ini

- Gambar: JPG, PNG, BMP, GIF, TIFF saling konversi; HEIC dan WebP sebagai sumber bila codec-nya terpasang; HEIC sebagai tujuan bila codec HEVC ada.
- Dokumen lewat LibreOffice yang sudah dibundel (tidak perlu memasang apa pun): DOCX/DOC/ODT/RTF/TXT, XLSX/XLS/ODS, PPTX/PPT/ODP ke PDF dan ke format lain dalam keluarganya.
- PDF: ke JPG/PNG/BMP/GIF/TIFF/HEIC per halaman, ke DOCX/DOC/ODT dan PPTX/PPT/ODP, dan ke **DXF/DWG** dengan pilihan satuan, skala, halaman, teks, dan penggabungan garis. PDF hasil scan ditelusuri jadi polyline.
- DXF ↔ DWG, dan DXF/DWG ke PDF.
- Verifikasi setiap hasil: SHA-256 per chunk 1 MiB dibaca ulang dari disk, lalu file dibuka ulang dengan decoder yang sesuai. Riwayat lokal yang bisa dihapus atau dimatikan.

Belum ada: konversi audio/video.

## Cara mencoba tanpa memasang (portable)

1. Unduh `Condec_v0.1.0-beta.1_x64_portable.zip` dan ekstrak ke folder mana saja.
2. Jalankan `Condec.exe`. Kalau SmartScreen muncul, pilih **More info** lalu **Run anyway** (berkasnya belum ditandatangani penerbit tepercaya).

Versi portable membawa .NET, Windows App Runtime, dan LibreOffice sendiri. Tidak ada yang dipasang atau didaftarkan; data aplikasi tetap di `%LOCALAPPDATA%\Condec`. Bedanya dengan MSIX hanya: tidak ada di Start menu dan tidak mendaftar sebagai pembuka jenis file.

## Cara memasang (MSIX)

Paket ini ditandatangani sertifikat uji, bukan sertifikat dari penerbit tepercaya, jadi Windows perlu diberi tahu sekali untuk mempercayainya.

1. Unduh `Condec_v0.1.0-beta.1_x64.msix` dan `Condec.cer`.
2. Buka PowerShell **sebagai administrator**, lalu jalankan di folder unduhan:
   ```powershell
   Import-Certificate -FilePath .\Condec.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
   ```
3. Klik dua kali berkas `.msix` dan pilih **Install**. Atau dari PowerShell:
   ```powershell
   Add-AppxPackage -Path .\Condec_v0.1.0-beta.1_x64.msix
   ```
4. Kalau muncul pesan bahwa paket **Microsoft.WindowsAppRuntime.2** dibutuhkan, pasang Windows App Runtime 2.5 dari Microsoft (App Installer biasanya mengunduhnya sendiri kalau Microsoft Store tersedia).

Prasyarat: Windows 10 versi 1809 (build 17763) atau lebih baru, 64-bit. Ukuran paket sekitar 260 MB (MSIX) dan 300 MB (portable) karena membawa LibreOffice.

Periksa unduhan dengan `SHA256SUMS.txt`:
```powershell
Get-FileHash .\Condec_v0.1.0-beta.1_x64.msix -Algorithm SHA256
```

## Catatan privasi

Tidak ada koneksi jaringan, telemetri, atau pengecekan pembaruan. Paket tidak meminta izin `internetClient`. Sumber lengkap dan daftar lisensi pihak ketiga ada di repositori ini.

## Diketahui

- Hanya x64. Build x86 dan ARM64 belum membawa LibreOffice.
- Sertifikat uji berbeda dengan sertifikat rilis stabil nanti; saat itu paket harus dicopot dan dipasang ulang.
- PDF → DXF/DWG: lebar garis dan garis putus-putus belum dipetakan ke lineweight dan linetype; isian ditulis sebagai outline tertutup.
