Condec's first pre-release: a Windows file converter that runs entirely on your device, with no internet connection.

## What's in this version

- Images: JPG, PNG, BMP, GIF, TIFF convert to each other; HEIC and WebP as a source when the codec is installed; HEIC as a target when the HEVC codec is present.
- Documents through a bundled copy of LibreOffice (nothing to install): DOCX/DOC/ODT/RTF/TXT, XLSX/XLS/ODS, PPTX/PPT/ODP to PDF and to other formats in their own family.
- PDF: to JPG/PNG/BMP/GIF/TIFF/HEIC per page, to DOCX/DOC/ODT and PPTX/PPT/ODP, and to **DXF/DWG** with a choice of units, scale, pages, text, and line joining. Scanned PDFs are traced into polylines.
- DXF ↔ DWG, and DXF/DWG to PDF.
- Every result is verified: a SHA-256 per 1 MiB chunk read back from disk, then the file is reopened with the matching decoder. Local history that can be cleared or turned off.

Not yet included: audio/video conversion.

## Trying it without installing (portable)

1. Download `Condec_v0.1.0-beta.1_x64_portable.zip` and extract it anywhere.
2. Run `Condec.exe`. If SmartScreen appears, choose **More info** then **Run anyway** (the file isn't signed by a trusted publisher yet).

The portable build brings its own .NET, Windows App Runtime, and LibreOffice. Nothing is installed or registered; app data still lives in `%LOCALAPPDATA%\Condec`. The only differences from the MSIX: no Start menu entry and no file-type associations.

## Installing (MSIX)

This package is signed with a test certificate, not one from a trusted publisher, so Windows needs to be told once to trust it.

1. Download `Condec_v0.1.0-beta.1_x64.msix` and `Condec.cer`.
2. Open PowerShell **as administrator** and run this in the download folder:
   ```powershell
   Import-Certificate -FilePath .\Condec.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
   ```
3. Double-click the `.msix` file and choose **Install**. Or from PowerShell:
   ```powershell
   Add-AppxPackage -Path .\Condec_v0.1.0-beta.1_x64.msix
   ```
4. If you're told the **Microsoft.WindowsAppRuntime.2** package is required, install Windows App Runtime 2.5 from Microsoft (App Installer usually fetches it automatically if the Microsoft Store is available).

Requirements: Windows 10 version 1809 (build 17763) or later, 64-bit. Package size is around 260 MB (MSIX) and 300 MB (portable) because both bundle LibreOffice.

Check your download with `SHA256SUMS.txt`:
```powershell
Get-FileHash .\Condec_v0.1.0-beta.1_x64.msix -Algorithm SHA256
```

## Privacy notes

No network connections, telemetry, or update checks. The package doesn't request the `internetClient` capability. Full source and third-party license notices are in this repository.

## Known limitations

- x64 only. The x86 and ARM64 builds don't bundle LibreOffice yet.
- The test certificate differs from the future stable-release certificate; the package will need to be removed and reinstalled when that happens.
- PDF → DXF/DWG: line widths and dash patterns aren't mapped to lineweights and linetypes yet; fills are written as closed outlines.
